# 野去 H5 Demo

这是“户外推进（新）”小程序前端全量重设计的第一版 H5 演示。它用静态数据模拟真实用户路径，先验证页面结构、信息层级和核心动作，再回写到微信小程序。

## 打开

无需安装依赖。直接打开 `index.html`，或在本目录运行：

```bash
python3 -m http.server 4173
```

然后访问 <http://127.0.0.1:4173>。

## 这版包含

- 首页：一句话输入、快速示例、出发地状态和可信说明。
- 结果页：筛选、关键词搜索、来源、匹配理由、收藏和加入路线。
- 详情页：距离、时间、难度、出发前确认、参考走法和反馈入口。
- 反馈页：问题标签、说明、分享偏好和提交反馈。
- 桌面与手机响应式布局，手机端采用页面级返回和操作入口。

## 设计基线

视觉契约见 [DESIGN.md](./DESIGN.md)。本轮采用本地 `design-md-style-library` 的 `apple` mobile 基线，并转译为项目自己的户外色彩和信息表达，不复制品牌资产。

## 说明

- 当前使用静态 mock 数据，不连接 Java、Python、MySQL 或微信云托管。
- 通过浏览器交互验证产品结构；真实接口接入留到小程序重构阶段。
