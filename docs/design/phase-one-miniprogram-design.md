# 设计文档：一期小程序体验调整

日期：2026-09-24  
主导岗位：frontend-ui-designer  
状态：v1 / 本轮开发输入

## 1. 设计目标

让用户只做一件事：输入一句诉求，然后看到来源可靠的候选路线，并可以明确采纳。

## 2. 页面变化

### 首页

- 保留现有 Field Guide 风格；
- 强化一句话输入；
- 高级筛选保留但弱化为补充选项；
- 主按钮语义改为“查找可靠路线”。

### 结果页

- 路线卡展示“候选参考”；
- 展示来源、采集时间和匹配理由；
- 增加明确“采纳路线”动作；
- 未采纳路线不得称为已收藏或正式路线。

### 详情页

- 对候选结果显示来源和不确定性；
- 已采纳后显示“已进入路线资产”；
- 反馈入口保留。

## 3. 状态

- `candidate`：候选参考；
- `adopting`：采纳中；
- `adopted`：已采纳，正式落地；
- `adopt_failed`：采纳失败，可重试。

## 4. 人工验收重点

- 首页是否能一句话发起；
- 结果页是否能看懂来源；
- 用户是否明确知道“采纳路线”才会落地；
- 采纳后反馈是否清楚。
