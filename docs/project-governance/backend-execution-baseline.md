## 原型与架构差异的本轮决定

- 任何路线详情都能进入纠错，因此反馈支持候选和正式资产；不要求先加入。
- 候选详情与正式资产详情使用独立 GET 地址，分享冷启动只返回公开路线快照，不返回查询、坐标起点或匿名会话。
- 原型 2 秒强制演示回退改为 5 秒请求预算；预览必须显式启用且不得进入正式资产。
- “公开分享”是明确布尔字段，不能由它推导“已经去过”。API 失败仅保存本机草稿，不显示服务端已收到。
- H2 用于本地事务验证，MySQL 是目标生产数据库；H2 通过不等于 MySQL 迁移、并发或部署验收通过。
- 未配置外部来源时返回无结果或明确降级；mock 只出现在显式演示模式，不标为真实攻略/地图证据。

## 反向思考卡

客观问题：旧方案遗漏候选反馈、把 2 秒演示计时器当成服务 SLA，且尚无生产身份认证、真实来源和数据库连接证据。影响是原型动作无法真实完成、预览被误当正式数据、重复请求产生副作用。

决定：优先实现并验证事务、幂等、详情和反馈；开发前统一契约，用现有依赖离线构建。保留 UI 结构，将错误和提交结果如实反馈。未发现本地实现阻塞；建议进入实现。真实 MySQL、正式身份鉴权和授权来源仍是上线门禁，不以本地测试替代。
