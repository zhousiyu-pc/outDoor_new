## UI Mode

- 主基线：local `design-md-style-library` 的 `wise` mobile consumer 模式。
- 项目化视觉：浅灰绿画布、白色圆角卡、深墨色标题、户外绿主操作色、橙色不作为主色。
- 首页模式：顶部轻导航 → 信任 badge → 一句话输入卡 → 主 CTA → 示例词 → 上下文控件 → 信任说明 → 二级筛选。
- 明确不复制 Wise 品牌色、字体、文案或品牌资产。

## Direct Adoption

- `text-input`：映射为大尺寸自然语言 textarea。
- `button-primary`：映射为全宽胶囊主按钮。
- `card-content`：映射为输入卡和上下文卡。
- `card-feature-dark`：映射为“来源 / 不确定性 / 采纳”信任卡。
- `badge-positive`：映射为“每条路线都有出处，出发更放心”。

## Copy Direction

- 主语从“系统/后台”改为“我们”，让用户先感知获得的帮助。
- “候选、入库、正式资产、Skill、落地”只保留在内部文档，不直接出现在用户端。
- 首页使用“说说你想怎么走”“帮我找路线”“喜欢再收进你的路线”等生活化表达。
- 结果页使用“参考路线”“加入我的路线”“出发前看一眼”等决策语言。
