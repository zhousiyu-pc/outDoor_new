## Context

一期产品要求用户只输入一句诉求，当前首页却将出发地、时间、快捷标签和结构化筛选共同作为主入口，形成表单感和决策负担。

## Goals / Non-Goals

**Goals:**
- 让一句话输入成为首页唯一主任务。
- 使用 Field Guide 的安静、低噪声视觉语言承载输入。
- 出发地和时间保留为次级上下文，不阻塞输入。

**Non-Goals:**
- 不删除已有高级筛选逻辑。
- 不修改推荐 API 或表单数据结构。
- 不改变结果页、详情页和反馈页业务行为。

## Decisions

1. 用 `textarea` 替代单行输入，允许用户自然表达完整诉求。
2. 用两个低层级上下文入口承载出发地和时间。
3. 将高级筛选放在折叠区，防止用户误以为必须填写。

## Risks / Trade-offs

- [自然语言表达不完整] → 后端 / Agent 负责从一句话中提取条件，并在结果页展示不确定性。
- [部分老用户仍习惯筛选] → 保留高级筛选作为补充入口。
